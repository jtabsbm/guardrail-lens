why

Guardrails look solid in demos and fail in production, because the failure modes are structural, not lexical. Every one of these gaps shipped in a public baseline guardrail — and was found by this exact battery.

⇗

The URL was scanned. The body wasn't.

First-key-only target extractors check url and stop. Secrets ride in the data field of a clean-looking POST and sail straight through.

✉

Clean words, dirty intent.

A confused deputy isn't caught by content filters: the email body is harmless, the action — sending workspace data to an attacker's address — is not.

⏱

Windows decay. Dataflow doesn't.

Read an untrusted email, interleave a few benign fs.read hops, and a call-time taint window reports clean right when the dangerous call fires.

the battery

44 probes across five families — 38 attacks plus 6 positive controls that any baseline must catch. Controls that fail are flagged separately: that's a broken contract, not just a hard case.

how it works

Zero dependencies, zero network, zero execution of payload calls — the lens simulates tool calls locally and reads your guardrail's verdicts.

Point it at your guardrail class

Anything with decide(tool_name, tool_args, context) → Decision — the aicomp_sdk contract, or duck-typed equivalent. guardrail-lens my_package.guardrails:MyGuardrail

The battery fires

Each probe replays the concrete tool calls a real attack would induce — with recent_sources taint context set the way the harness sets it. Nothing is executed; verdicts are read, not suffered.

You get a grade and a fix list

Exit code 0 when the battery is fully blocked, 1 when anything lands — a drop-in CI security gate. --json emits the full machine-readable report; every finding carries its severity, the exact call, the guardrail's own reason string, and hardening advice.

getting started

One command from clone to first report.

terminal
$ pip install git+https://github.com/jtabsbm/guardrail-lens.git $ guardrail-lens aicomp_sdk.guardrails.optimal:Guardrail # or against your own class, from Python: $ python -c " from guardrail_lens import default_battery, run_battery report = run_battery(MyGuardrail(), default_battery()) print(report.grade, report.total_risk) for r in report.landed: print(r.probe.id, r.probe.advice) " $ guardrail-lens --json my.guard:G > report.json # CI gate: exit 1 if anything lands
